# 에이전트 행동 강령 및 문서화 규칙

## 1. 로컬 파일 기록 원칙
- 모든 **Implementation Plan**과 **Task List**는 내부 아티팩트(Artifacts)에만 두지 말고, 프로젝트 루트의 `task.md` 파일에 즉시 기록하거나 업데이트하라.
- 에이전트의 분석 결과와 수정 계획은 사용자가 작업창에서 즉시 확인할 수 있도록 실제 파일 형태로 존재해야 한다.

## 2. 작업 절차 (3턴 루프 준수)
- **Planner 단계:** 수정 전 반드시 `task.md`에 원인 분석과 설계안을 작성하고 사용자의 승인을 받아라.
- **Implementer 단계:** 승인된 계획에 따라 코드를 수정하고, 터미널 명령을 통해 가상환경(`pytepod`) 내에서 테스트를 수행하라.
- **Reviewer 단계:** 작업 완료 후 `task.md`에 최종 검토 결과를 기록하고, 남아있는 `Problems(Pyre2)` 에러가 없는지 확인하라.

## 3. 환경 인지
- 루트의 `settings.json`과 `.pyre_configuration` 설정을 최우선으로 준수하여 가상환경 및 라이브러리 경로를 인식하라.
